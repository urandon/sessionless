# Documentation assets

This directory contains source-owned, reviewable images used by repository
documentation.

- `sessionless-webui-session.jpg` is generated from the built Svelte WebUI and
  the read-only fixture in `scripts/readme-visual-preview.mjs`.
- `readme-audit-before-2026-09-06.jpg` preserves the pre-change rendered README
  evidence referenced by `docs/readme-information-architecture.md`.

Do not add private screenshots, credentials, capability URLs, or opaque assets
without a documented source and refresh procedure.
